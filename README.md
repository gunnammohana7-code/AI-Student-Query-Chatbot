# AI-Student-Query-Chatbot# AI Student Query Chatbot

## Project Description
An AI-based chatbot that answers common student questions about college fees, internships, and placements.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Logistic Regression
- Gradio
- Google Colab

## Features
- Student query classification
- Automatic intent prediction
- Answers for common college-related questions
- Simple chatbot interface

## How to Run
1. Open the Google Colab notebook.
2. Run the cells from top to bottom.
3. Launch the Gradio interface.
4. Enter a student question and get a response.

## Project Notebook
The complete Python code is available in the `AI_Student_Query_Chatbot.ipynb` notebook in this repository.
